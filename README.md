# Westbridge Accessibility

An interactive companion to Westbridge University's *Digital Content Accessibility Guidelines* (TLEU-ACC-2019-v2.4) — a fictional university used in a PGDip case study.

- **Develop Your Brand** — tutorial, then a guided walkthrough: colours and contrast, typography, printable brand sheet.
- **Quick Reference** — searchable, filterable guideline checklist with a printable view.
- **Contrast checker** — WCAG 2.0 AA (4.5:1 normal text, 3:1 large text).

Next.js 15 · React 19 · TypeScript · Tailwind CSS 3 · GitHub Pages.

```bash
npm install
npm run dev
```

See [`docs/`](./docs/) for details and [`docs/04-deploy.md`](./docs/04-deploy.md) for deployment.
